# React Assignment - Theory

## 1. What is Emmet?
Emmet is a toolkit that helps developers write HTML
and CSS faster using abbreviations.

## 2. Library vs Framework
A library provides functionality that we call when
needed. A framework provides a broader structure
and often controls the application flow.

## 3. What is CDN?
CDN stands for Content Delivery Network. It delivers
files through distributed servers. In this assignment,
we use CDN links to load React without npm installation.

## 4. Why is React known as React?
React is named after its reactive approach to updating
user interfaces when data changes.

## 5. What is crossorigin?
The crossorigin attribute controls CORS handling
for supported cross-origin resources.

## 6. React vs ReactDOM
React provides APIs to define UI elements and components.
ReactDOM connects React with the browser DOM.

## 7. Development vs Production
Development builds provide helpful warnings and debugging.
Production builds are optimized for deployment.

## 8. Async vs Defer
Both allow external scripts to download without
blocking HTML parsing in the usual case.
Async executes when downloaded; defer executes
after HTML parsing, preserving order among deferred scripts.
