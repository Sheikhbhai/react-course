# React First Class Assignment 🚀

This repository contains my first React learning assignment. It covers the fundamentals of React, basic JavaScript DOM manipulation, and creating UI elements using React through CDN links.

## 📚 Theory Topics

The following concepts are covered in this assignment:

1. What is Emmet?
2. Difference between a Library and a Framework.
3. What is CDN and why do we use it?
4. Why is React known as React?
5. What is `crossorigin` in the script tag?
6. Difference between React and ReactDOM.
7. Difference between `react.development.js` and `react.production.js`.
8. Difference between `async` and `defer`.

## 💻 Practical Tasks

Created Hello World programs using three different approaches:

### 1. Using HTML
Created a basic Hello World page using HTML.

### 2. Using JavaScript DOM Manipulation
Used JavaScript to:
- Create an HTML element dynamically.
- Set its text content.
- Insert the element into the DOM using `appendChild()`.

### 3. Using React

Used React 18 through CDN links to:
- Load React and ReactDOM.
- Create React elements using `React.createElement()`.
- Create nested React elements.
- Initialize the React root using `ReactDOM.createRoot()`.
- Render elements using `root.render()`.

## ▶️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/react-first-class.git
   ```

2. Open the project folder in VS Code.

3. Navigate to any of the following folders:
   - `01-html`
   - `02-javascript-dom`
   - `03-react-cdn`

4. Open the respective `index.html` file in Google Chrome.

5. For the React example, ensure you have an active internet connection because React is loaded using CDN links.
